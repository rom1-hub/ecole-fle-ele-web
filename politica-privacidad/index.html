Política de privacidad

Información sobre el tratamiento de datos personales en École FLE et ELE.

2. Datos que podemos recibir

El formulario puede recibir nombre y apellidos, correo electrónico, número de WhatsApp, nivel de francés, objetivo, preferencia de contacto y mensaje.

3. Finalidad

Gestionar la solicitud de información, realizar el primer contacto, conocer el nivel y las necesidades comunicadas y explicar el funcionamiento de los cursos.

4. Base jurídica

La base jurídica se determinará según la finalidad y la forma en que se produzca el contacto. Cuando corresponda, el consentimiento será libre, informado e inequívoco y podrá retirarse.

5. Comunicaciones comerciales

La solicitud de prueba de nivel no implica por sí sola la suscripción a comunicaciones comerciales. Si se ofrece publicidad o suscripción, se solicitará el consentimiento correspondiente de forma separada cuando sea necesario.

6. Destinatarios y proveedores

Para prestar el servicio web y gestionar las solicitudes pueden intervenir proveedores tecnológicos. La web se publica mediante GitHub Pages y utiliza Cloudflare como proveedor de DNS, proxy y seguridad. El formulario de contacto utiliza FormSubmit para transmitir los datos de la solicitud a info@ecole-fle-ele.com. Estos proveedores pueden tratar datos técnicos necesarios para prestar sus servicios conforme a sus propias condiciones y políticas.

7. Conservación

Los datos de las solicitudes se conservarán durante el tiempo necesario para atender la petición y, cuando exista una relación contractual, durante los plazos legalmente exigibles.

8. Derechos

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación del tratamiento y, cuando proceda, portabilidad de tus datos, escribiendo a info@ecole-fle-ele.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

9. Seguridad

Se aplican medidas técnicas y organizativas razonables para proteger los datos frente a accesos no autorizados, pérdida o alteración.

10. Actualizaciones

Esta política podrá actualizarse cuando cambien los servicios, las herramientas utilizadas o la normativa aplicable.
